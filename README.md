# 1C Log Detective

**Инструмент для анализа технологических журналов 1С на Python.**

1C Log Detective — учебный и портфельный проект для диагностики ошибок и исследования событий технологического журнала 1С:Предприятие. Цель проекта — помогать разработчику быстрее находить значимые события, анализировать исключения и SQL-операции и формировать понятные диагностические отчёты.

Проект развивается поэтапно. Текущая реализация включает базовый CLI-анализатор, модули разбора и анализа событий, группировку исключений, анализ SQL-событий и исследование возможных связей между событиями блокировок и исключениями.

## Возможности

- Чтение и разбор событий технологического журнала.
- Потоковая обработка журнала для работы с большими файлами.
- Формирование текстовых диагностических отчётов.
- Анализ SQL-событий, включая запросы и сведения об их выполнении.
- Группировка исключений по категориям и деталям.
- Поиск временных и контекстных связей между событиями блокировок и исключениями.
- Обработка ошибок при чтении файлов.
- Автоматические тесты основных модулей.

**Важно:** обнаруженная временная или контекстная связь между событиями является диагностической гипотезой, а не доказательством причинно-следственной связи.

## Запуск

Для запуска базового CLI-анализатора используй пример:

```powershell
python main.py sample_log.txt report.txt ALL
```

Аргументы:

- `sample_log.txt` — исходный текстовый файл.
- `report.txt` — путь к создаваемому отчёту.
- `ALL` — фильтр событий.

Доступные фильтры базового CLI: `ALL`, `ERROR`, `WARNING`, `CRITICAL`.

## Автоматические тесты

Установи pytest:

```powershell
python -m pip install pytest
```

Запусти тесты из корневой папки проекта:
