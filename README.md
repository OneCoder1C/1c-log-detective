# 1C Log Detective

**CLI-анализатор журналов 1С на Python.**

1C Log Detective — инструмент на Python для анализа журналов, выявления ошибок и формирования диагностических отчётов. Проект предназначен для автоматизации задач диагностики и сопровождения информационных систем 1С.

Разработка ведётся поэтапно: текущая версия поддерживает анализ текстовых файлов, фильтрацию событий и формирование отчётов. Поддержка форматов технологического журнала 1С будет реализована на следующих этапах.

## Возможности

- Чтение текстового файла журнала.
- Фильтрация событий по уровням `ALL`, `ERROR`, `WARNING` и `CRITICAL`.
- Подсчёт найденных событий.
- Вывод рекомендаций по обнаруженным событиям.
- Формирование текстового отчёта.
- Обработка ошибок при отсутствии файла и использовании неизвестного фильтра.

## Запуск

Клонируйте репозиторий или скачайте его файлы. Перейдите в каталог проекта и выполните:

```powershell
python main.py sample_log.txt report.txt ALL
```

Аргументы команды:

- `sample_log.txt` — исходный файл журнала.
- `report.txt` — файл для сохранения отчёта.
- `ALL` — фильтр событий.

Доступные фильтры: `ALL`, `ERROR`, `WARNING`, `CRITICAL`.

## Запуск тестов

Установите pytest:

```powershell
python -m pip install pytest
```

Запустите тесты:

```powershell
python -m pytest -v
```
